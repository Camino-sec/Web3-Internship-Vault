# 合约部署实战

## 一句话解释
把 Solidity 智能合约编译、部署到区块链网络上，使其获得一个永久的合约地址，可以被任何人调用。

## 生活类比（注册公司）
- **交易 hash**：你的"注册申请回执"，证明你提交了申请
- **合约地址**：你的"营业执照号"，是公司在链上的唯一标识
- **MetaMask**：帮你签字的"公证人"，但真正的"工商局"是全网的矿工/验证者

## 完整部署流程

### 1. 编写合约
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
    uint256 private storedData;

    function set(uint256 x) public {
        storedData = x;
    }

    function get() public view returns (uint256) {
        return storedData;
    }
}
```

### 2. 编译合约
- 使用 Remix IDE 或 Hardhat 等工具
- 编译后生成 ABI（接口说明）和字节码（可执行代码）

### 3. 部署到网络
1. 选择网络（如 Monad Testnet）
2. 连接钱包（MetaMask）
3. 点击 Deploy
4. MetaMask 弹窗确认交易
5. 等待区块确认

### 4. 验证部署
- 获取合约地址
- 使用区块浏览器或 RPC 查询验证

## 关键概念

### 合约地址 vs 交易地址
| 概念 | 长度 | 作用 |
|------|------|------|
| 交易 hash | 66 字符（0x + 64 位十六进制） | 记录"我做了一件事" |
| 合约地址 | 42 字符（0x + 40 位十六进制） | 记录"这个合约在哪里" |

### Write vs Read 函数
- **Write 函数**（如 `set(42)`）：需要签名 + Gas，会改变链上状态
- **Read 函数**（如 `get()`）：免费调用，不改变状态

**生活类比**：写入是寄快递（要邮费），读取是查快递单号（免费）

### MetaMask 的角色
- MetaMask 是"签名器"，不是"执行器"
- 只负责帮你签名确认
- 真正的执行是矿工/验证者做的
- 签名完了还要等区块确认

## 链上数据验证

### 使用 RPC 直接查询
```bash
curl -s -X POST https://testnet-rpc.monad.xyz \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_getTransactionReceipt","params":["0xf00f..."],"id":1}'
```

### 数据解读
- 返回的数据是十六进制的
- 比如 `0x2a` 就是 42
- 把十六进制转换成十进制的过程，让我第一次直观感受到"链上数据是裸的"——没有中间层帮你翻译，一切都需要自己解读
