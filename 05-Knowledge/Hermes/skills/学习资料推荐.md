# 📚 学习资料推荐 Skill

## 触发词
`推荐资料` / `学什么` / `深入了解 [概念名]` / `resources [topic]`

## 功能描述

根据 Luvia 当前的学习阶段和主题，推荐高质量的学习资料。

## 资源来源优先级

1. **Obsidian Vault** — 先检查已有笔记
2. **Monad 官方文档** — 训练营核心内容
3. **LXDAO 社区** — 社区资源和讨论
4. **ethereum.org** — 以太坊官方学习资源
5. **YouTube/B站** — 视频教程
6. **GitHub** — 开源项目和代码示例

## 推荐格式

```
📚 关于 [主题] 的学习资料：

📖 文章/文档：
1. [标题](链接) — 一句话说明
2. [标题](链接) — 一句话说明

🎥 视频：
1. [标题](链接) — 一句话说明

💻 代码/项目：
1. [项目名](链接) — 一句话说明

📝 你的笔记：
- [[已有概念笔记]] — 已有笔记链接
```
