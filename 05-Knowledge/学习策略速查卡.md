# 🃏 学习策略速查卡

---

## 🟢 六大证据学习策略

### 1. 间隔练习 `[间隔重复]`
**一句话**：拉开复习间隔，不要考前突击
**操作**：当天 → 1天 → 3天 → 7天 → 14天 → 30天
**工具**：Anki 自动管理

### 2. 提取练习 `[提取练习]`
**一句话**：合上书回忆，比重读有效 10 倍
**操作**：学完一节 → 合上书 → 写 3-5 个问题 → 不看答案回答
**高级**：Blurting 法（5 分钟狂写，对照标遗漏）

### 3. 精细加工 `[精细加工]`
**一句话**：追问"为什么"，建立深层联系
**操作**：每学一个概念问——像什么？不同什么？哪里用到？

### 4. 具体实例 `[具体实例]`
**一句话**：抽象概念找 2-3 个具体案例
**操作**：学理论 → 找例子 → 比较共同点和差异 → 自己举新例子

### 5. 双重编码 `[双重编码]`
**一句话**：文字 + 图表结合，两个通道加强记忆
**操作**：写 2-3 句解释 + 画一张图/流程图/思维导图

### 6. 交错练习 `[交错练习]`
**一句话**：混合练习，不要只刷一种题型
**操作**：ABC-ABC-ABC，不是 AAA-BBB-CCC

## 🔴 能力错觉陷阱

| ❌ 错觉 | ✅ 真实检验 |
|---------|-----------|
| 看懂了 = 会做了 | 合上书能解释才算会 |
| 划了重点 = 记住了 | 能回忆出来才算记住 |
| 看完视频 = 学完了 | 能做出来才算学完 |
| 收藏了 = 掌握了 | 用过才算掌握 |

## 🎯 每日 40 分钟协议

```
[0 min]  🧘 启动仪式：泡茶 → 深呼吸 → 手机隔离
[0-5 min] 👀 预习：扫描标题
[5-30 min] 🎯 专注：1 个番茄钟
[30-35 min] 🗣️ 费曼回顾：合上书解释
[35-40 min] 🚦 红绿灯 + 记录
```

---

## 🚦 红绿灯法

| 颜色 | 含义 | 行动 |
|------|------|------|
| 🟢 | 能教给别人 | 间隔重复 |
| 🟡 | 有盲区 | 精细加工追问 |
| 🔴 | 完全不会 | 优先攻克 |

---

## 🧠 费曼技巧四步

1. 选一个概念
2. 用简单语言解释（假设对方 10 岁）
3. 找到卡住的地方 → 那里理解不够深
4. 回去重学那个部分，再简化解释

---

## ⏰ 番茄钟

- 25 分钟专注 + 5 分钟休息
- 遇到难题卡住 → 休息，让发散模式工作
- 睡前回顾关键概念 → 睡眠巩固记忆

---

## 📱 环境管理

- 手机放另一个房间（研究：手机在视线内就降低认知）
- 固定学习地点（形成条件反射）
- 学新概念 → 安静环境
- 做重复练习 → 可听无歌词音乐

---
