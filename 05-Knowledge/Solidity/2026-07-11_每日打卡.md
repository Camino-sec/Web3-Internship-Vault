### 1.3 Bool 布尔类型

**核心概念**：开关思维，只有 `true` / `false` 两种状态

**生活类比**：就像电灯开关，只有开和关，没有中间状态

**运算符**：
- `!`（NOT）：取反，开变关，关变开
- `&&`（AND）：两个都开才开
- `||`（OR）：任意一个开就开

**代码示例**：
```solidity
bool isStudent = true;
bool isAdult = false;

// 逻辑运算
bool canEnroll = isStudent && isAdult;  // false（需要两个条件都满足）
bool canEnter = isStudent || isAdult;   // true（满足一个就行）
bool isNotStudent = !isStudent;         // false（取反）
```

**掌握度**：🟡 基本理解，需要更多练习

### 1.4 整型运算

**核心概念**：`uint`（无符号整数）有边界限制

**关键知识点**：
- Solidity 0.8+ 内置溢出保护（会自动报错）
- 除法运算会丢弃小数部分（`5 / 2 = 2`，不是 2.5）

**生活类比**：就像一个有刻度的尺子，最小是 0，最大是 2^256-1

**代码示例**：
```solidity
uint256 maxSupply = 10000;
uint256 currentSupply = 9999;

// 安全运算（Solidity 0.8+ 自动检查溢出）
uint256 newSupply = currentSupply + 1;  // 10000，正常
// uint256 overflow = maxSupply + 1;    // 报错！溢出

// 除法丢弃小数
uint256 result = 5 / 2;  // 结果是 2，不是 2.5
uint256 remainder = 5 % 2;  // 结果是 1（取余数）
```

**掌握度**：🟢 理解扎实

### 1.5 位运算

**核心概念**：直接操作二进制位，是"底层操作"

**运算符**：
- `&`（按位与）：两位都为 1 才为 1
- `|`（按位或）：任意一位为 1 就为 1
- `^`（异或）：两位不同为 1
- `~`（取反）：0 变 1，1 变 0
- `<<`（左移）：所有位向左移动
- `>>`（右移）：所有位向右移动

**核心价值**：**省 Gas！** 一个 `uint256` 能存 256 个开关，比存 256 个 `bool` 便宜得多

**生活类比**：就像一排灯泡的批量操作，一次操作能同时控制多个灯泡

**代码示例**：
```solidity
// 用一个 uint256 存储 256 个布尔值
uint256 public permissions;

// 设置第 3 位为 1（开启权限）
function setPermission(uint8 index) public {
    permissions |= (1 << index);
}

// 检查第 3 位是否为 1（是否有权限）
function hasPermission(uint8 index) public view returns (bool) {
    return (permissions & (1 << index)) != 0;
}

// 清除第 3 位（关闭权限）
function clearPermission(uint8 index) public {
    permissions &= ~(1 << index);
}
```

**Gas 对比**：
- 存储 256 个 `bool`：需要 256 个存储槽，约 256 × 20,000 = 5,120,000 Gas
- 存储 1 个 `uint256`：只需要 1 个存储槽，约 20,000 Gas
- **节省 99.6% 的 Gas！**

**掌握度**：🟡 概念理解，实际应用需练习

## 💡 今日核心收获

### 技术层面
1. **Solidity 越底层越省钱**：位运算虽然抽象，但能大幅降低 Gas 成本
2. **溢出保护是双刃剑**：Solidity 0.8+ 自动检查溢出，但也要注意除法丢弃小数的问题
3. **布尔逻辑是基础**：所有复杂的条件判断都建立在 `&&`、`||`、`!` 之上

### 方法论层面
1. **生活类比帮助理解**：把抽象概念（位运算）比作具体场景（灯泡操作）更容易记忆
2. **Gas 优化意识**：从学习基础语法开始就要培养"省 Gas"的思维习惯
