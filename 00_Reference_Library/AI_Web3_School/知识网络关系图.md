## ⛓️ Web3 基础知识链

```
区块链是什么
    │
    ├──构建于──→ 以太坊入门
    │               │
    │               └──运行──→ 智能合约
    │                             │
    │                             ├──实现──→ DeFi 概览 ──→ Tokenomics
    │                             │
    │                             └──→ 链上隐私与隐私协议
    │
    └──管理──→ 钱包与交易
                    │
                    ├──类型──→ EOA / 智能账户 / 多签
                    │
                    └──消耗──→ Gas 费
```

### 关系说明

| 关系 | 从 | 到 | 含义 |
|------|----|----|------|
| 构建于 | 区块链 | 以太坊 | 以太坊是区块链的一种实现 |
| 运行 | 以太坊 | 智能合约 | 智能合约运行在以太坊上 |
| 实现 | 智能合约 | DeFi | DeFi 用智能合约实现金融功能 |
| 管理 | 区块链 | 钱包 | 钱包是管理链上资产的工具 |
| 类型 | 钱包 | 账户类型 | 不同钱包 = 不同安全边界 |
| 消耗 | 钱包 | Gas 费 | 交易需要支付 Gas 手续费 |

## 🤖 AI 基础知识链

```
LLM 是什么
    │
    ├──基础──→ 神经网络基础 ──→ 反向传播算法 ──→ 梯度下降法
    │
    ├──驱动──→ Prompt 工程
    │
    └──核心──→ AI Agent
                  │
                  └──需要──→ Agent 记忆系统

独立概念：
    Vibe Coding（AI 辅助编程）
    DevRel 与 Ops 的区别（职业方向）
```

### 关系说明

| 关系 | 从 | 到 | 含义 |
|------|----|----|------|
| 基础 | LLM | 神经网络 | LLM 的底层是神经网络 |
| 驱动 | LLM | Prompt 工程 | 用 Prompt 驱动 LLM 输出 |
| 核心 | LLM | AI Agent | Agent 是 LLM 的核心应用 |
| 需要 | AI Agent | 记忆系统 | Agent 需要记忆来保持上下文 |

## 🔗 AI × Web3 交叉关系

```
                    AI Agent（执行者）
                        │
          ┌─────────────┼─────────────┐
          │             │             │
          ▼             ▼             ▼
   Agentic Commerce  AI Security   Vibe Coding
   （自主交易）      （安全边界）   （AI 编程）
          ▲
          │
    智能合约（基础设施）


    区块链（底层）──→ DePIN（去中心化物理基础设施）

    DeFi（金融）──→ Tokenomics（代币经济）

    以太坊（扩容）──→ Layer 2

    智能合约（数据）──→ Chainlink 与预言机
```

### 交叉关系说明

| 交叉 | AI 侧 | Web3 侧 | 交叉点 |
|------|--------|----------|--------|
| Agentic Commerce | AI Agent（执行者） | 智能合约（基础设施） | Agent 自主在链上交易 |
| DePIN | — | 区块链（底层） | 用代币激励硬件资源 |
| Tokenomics | — | DeFi（金融） | 代币经济模型设计 |
| AI Security | AI Agent（执行者） | 链上隐私 | Agent 的安全边界 |
| Layer 2 | — | 以太坊（扩容） | 提升链上性能 |
| 预言机 | — | 智能合约（数据） | 链上获取链下数据 |
