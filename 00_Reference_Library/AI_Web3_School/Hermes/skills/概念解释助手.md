# 💡 概念解释助手 Skill

## 触发词
`解释 [概念]` / `什么是 [概念]` / `[概念] 是什么意思` / `explain [concept]`

## 功能描述

用生活化的方式解释 Web3/AI 概念，先检查 vault 中是否已有笔记，再补充解释。

## 工作流程

### Step 1：检查已有笔记
```
扫描 02-Concepts/ 文件夹，查找文件名或内容中包含该概念的笔记
如果找到 → 引用已有笔记并补充
如果没找到 → 从零解释
```

### Step 2：解释结构

**一句话定义**
> 用最简单的话说清楚

**生活类比**
> 用日常场景类比，让非技术人员也能懂

**和已知概念的关系**
> 关联到 Luvia 已经学过的概念，用 [[双链]] 链接

**在 AI × Web3 中的应用**
> 这个概念在实际项目中怎么用

### Step 3：询问是否创建笔记
```
解释完后问：
"要不要我帮你创建一篇概念笔记到 02-Concepts/？"
```

## 示例对话

```
Luvia: 什么是 MEV？
Hermes: 💡 MEV（Maximal Extractable Value）

【一句话定义】
矿工/验证者通过调整交易顺序能额外赚到的钱。

【生活类比】
想象你在超市排队结账，有人给收银员 10 块钱"小费"让他先处理自己的单。MEV 就是链上的"插队费"——有人愿意多付 Gas 让自己的交易排在前面，因为这样做能赚到更多钱。

【和已知概念的关系】
- [[Gas费]] — MEV 和 Gas 密切相关，竞价越高越容易被优先打包
- [[智能合约]] — 很多 MEV 机会来自 DEX 套利

【在 AI × Web3 中的应用】
AI Agent 可以自动检测 MEV 机会并执行套利，但这也带来了伦理问题。

要我帮你创建一篇 [[MEV]] 概念笔记吗？
```
