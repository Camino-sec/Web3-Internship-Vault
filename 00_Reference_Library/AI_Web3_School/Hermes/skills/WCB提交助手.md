# 📤 WCB 提交助手 Skill

## 触发词
`wcb` / `提交` / `打卡` / `submit`

## 功能描述

帮助 Luvia 整理本周需要提交到 WCB 平台的内容，并生成可直接粘贴的提交格式。

## 工作流程

### Step 1：收集本周产出
```
读取本周的：
- Daily Notes（06-Daily/ 中本周的文件）
- SOP 周报（03-SOP-Weekly/ 中最新的）
- 概念笔记（02-Concepts/ 中本周新增的）
- 代码/项目链接（从笔记中提取）
```

### Step 2：整理成提交格式

**学习笔记提交**：
```
本周学习笔记：
- [日期] 主题：简要内容
- [日期] 主题：简要内容
...
完整笔记链接：[Obsidian 笔记链接或 GitHub 链接]
```

**代码/项目提交**：
```
代码仓库：[GitHub 链接]
Demo 地址：[Demo 链接]
合约地址：[测试网合约地址]（如有）
交易哈希：[交易哈希]（如有）
```

**社交媒体分享**：
```
生成 Twitter/X 分享帖草稿：
- 本周学到了什么
- 最大的收获
- 遇到的挑战
- 下周计划
格式：280 字以内，带 hashtag
```

### Step 3：提醒截止时间
- 检查当前日期，提醒 WCB 提交截止时间
- 如果已过截止时间，提醒补交

## 示例对话

```
Luvia: wcb
Hermes: 📤 本周 WCB 提交整理：

【学习笔记】
- 7/6 搭建了 Obsidian 学习 Vault
- 7/6 学习了 Gas 费概念
- 7/6 配置了 Hermes Agent

【代码/项目】
- 暂无代码产出（本周以搭建环境为主）

【社交媒体分享草稿】
"开始了 Web3 暑期实习！第一周搭好了学习系统，学了 Gas 费的概念。Monad 的高吞吐量设计真的很有趣 🚀 #Web3 #Monad #LXDAO #AIxWeb3"

需要我帮你调整内容吗？
```
