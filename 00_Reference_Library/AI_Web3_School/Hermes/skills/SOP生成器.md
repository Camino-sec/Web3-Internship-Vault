# 📋 SOP 生成器 Skill

## 触发词
`生成周报` / `sop` / `本周总结` / `weekly summary`

## 功能描述

自动读取本周的 Daily Notes 和概念笔记，生成结构化的 SOP 周报初稿，**包含认知科学元素**。

## 工作流程

### Step 1：识别本周笔记
```
扫描 06-Daily/ 文件夹，找出本周（周一到周日）的所有 .md 文件
扫描 02-Concepts/ 文件夹，找出本周新增的 .md 文件
```

### Step 2：提取关键信息
从每篇笔记中提取：
- 学到了什么（`## 今日学到什么` 部分）
- 关联概念（`## 关联概念` 部分）
- 遇到的问题（`## 遇到的问题 / 卡点` 部分）
- 完成的任务（`## 完成的小任务` 部分）
- 红绿灯状态（`## 🚦 红绿灯自评` 部分）
- 费曼回顾（`## 🗣️ 费曼回顾` 部分）
- 每日微反思（`## 🧠 每日微反思` 部分）

### Step 3：生成 SOP 初稿（含认知科学元素）

```markdown
# Week X SOP

## 本周目标回顾
> 对照上周设定的目标，检查完成情况

## 🚦 红绿灯状态变化
> 统计本周有多少概念从红→黄→绿
| 概念 | 上周状态 | 本周状态 |
|------|----------|----------|
| [从笔记中提取] | | |

## 学习产出
### 课程学习
- [从笔记中提取]

### 动手实践
- [从笔记中提取]

## 新增概念
- [[概念1]] — 一句话说明
- [[概念2]] — 一句话说明

## 踩坑与难点
| 问题 | 原因 | 解决方案 |
|------|------|----------|
| [从笔记中提取] | | |

## 关键收获
1. [从笔记中总结]
2. [从笔记中总结]
3. [从笔记中总结]

## 🔄 间隔复习安排
> 根据间隔重复节奏，列出下周需要复习的旧概念
| 概念 | 上次学习 | 下次复习 |
|------|----------|----------|
| [自动计算] | | |

## 🧠 元认知反思
> 基于本周的每日微反思，汇总三个问题的回答

**哪种学习方式本周最有效？**
> [从每日微反思中提取]

**哪些任务我总是在拖延？可以怎么调整？**
> [从笔记中分析]

**如果重新开始这周，我会改变什么？**
> [综合分析]

## 下周待办
- [根据未完成的问题和课程大纲建议]
```

### Step 4：发送给 Luvia
- 将初稿发到 Telegram
- 提示："这是本周 SOP 初稿，请审核修改后保存到 `03-SOP-Weekly/`"
- 特别提醒："元认知反思部分需要你自己填写，这是整个 SOP 最有价值的部分"
