## 🔧 本地预览

### 使用 Obsidian（推荐）

1. 下载 [Obsidian](https://obsidian.md/)
2. 打开 Obsidian → **Open folder as vault**
3. 选择本仓库目录
4. 启用插件：Daily notes、Dataview、Templater

本仓库所有笔记均为标准 Markdown 格式，可使用任意 Markdown 编辑器打开：
- VS Code + Markdown Preview Enhanced
- Typora
- Mark Text
