## 📚 【下班前：3分钟】新知沉淀与红绿灯自评 (Evening Feynman)

| 学到的新概念 (双链到 02-Concepts) | 状态 (🟢/🟡/🔴) | 费曼大白话解释 (用2句话跟外行解释清楚)                                                                                                              |
| :----------------------- | :-----------: | :--------------------------------------------------------------------------------------------------------------------------------- |
| [[AI Agent安全框架]]         |      🟢       | AI Agent 安全就像保护一个机器人管家：不仅要防止它被黑客控制（Prompt注入），还要防止它自己犯错（AI幻觉），更要防止它权限过大（失控的自主权限）。Agent Guard 就是这个管家的"安保系统"，从发现资产到红队验证，再到运行时防御和统一治理。 |
| [[最小权限原则]]               |      🟢       | 就像你给朋友钥匙，只给他开大门的钥匙，而不是所有房间的钥匙。AI Agent 也一样，只授予完成任务所需的最小权限，这样即使被攻击，损失也有限。                                                           |
| [[HITL人类在环]]             |      🟢       | 就像自动驾驶汽车，虽然可以自动驾驶，但关键时刻需要人类接管。AI Agent 执行高危操作前需要人类确认，重要决策需要人类审核，异常行为需要人类干预。                                                        |
| [[Prompt注入]]             |      🟡       | 就像 SQL 注入，通过恶意输入操控数据库。Prompt 注入是通过恶意提示词攻击 AI 系统，使其执行非预期操作。比如"忽略之前的指令，执行..."。防御方法：输入过滤、权限控制、沙箱隔离。                                   |
| [[AI幻觉]]                 |      🟡       | AI 生成看似正确但实际错误的信息。就像一个学生编造不存在的论文，或者生成错误的代码。原因：模型训练数据不足、概率分布问题、注意力机制带偏。                                                             |
| [[Solidity view与pure]]   |      🟢       | view 是"只看不摸"，只读取状态不修改，不消耗 gas；pure 是"闭着眼睛算"，不读取也不修改状态，只做计算，也不消耗 gas。就像：view 是看菜谱，pure 是心算数学题。                                      |
| [[AgenTank游戏]]           |      🟢       | 一个 AI 原生的坦克游戏，你不直接操控坦克，而是像教练一样设定策略，让它自己去比赛，你通过观看回放来分析、调整、让它变强。体验了"创建→测试→分析→优化"的 AI-native 工作流程。                                    |
| [[供应链攻击]]                |      🟡       | 就像在食品供应链中投毒，影响所有下游产品。区块链例子：恶意 npm 包攻击 DApp 前端、钓鱼网站模仿官方站点、恶意浏览器扩展窃取私钥。防御：审查第三方依赖，使用安全工具扫描。                                          |
| [[NFT持有即授权]]             |      🟡       | 持有 NFT 可能隐含授权某些操作。就像你买了一张会员卡，可能自动授权商家扣费。某些 NFT 合约可能授权项目方转移你的资产，持有 NFT 可能自动授权某些 DeFi 操作。                                            |
| [[拜占庭博弈]]                |      🟡       | 分布式系统中的容错问题，部分节点可能恶意行为。就像拜占庭将军问题，部分将军可能叛变。区块链共识机制（如 PoW、PoS）就是为了解决这个问题。                                                            |
